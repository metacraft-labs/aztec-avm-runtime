aztec-avm-runtime — the dev node, in a Web Worker

This is a simulator. No proofs are produced, there is no L1 and no network. Every receipt carries simulated: true and proving: 'none', and the runtime writes one disclosure line naming the pinned protocol version before it will run anything. That is §8.4, and moving the runtime into a worker does not move that.

The chain runs on a second thread. This page holds a client; the worker holds the runtime, assets/avm.wasm and the whole world state. Block production therefore keeps going while this thread is busy — button 3 blocks this thread for four seconds on purpose, and button 4 does the same thing with the runtime on this thread so the difference is a measurement rather than a claim.
