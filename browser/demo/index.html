aztec-avm-runtime — public transactions, in this tab

This is a simulator. No proofs are produced, there is no L1 and no network. Every receipt carries simulated: true and proving: 'none', and the runtime writes one disclosure line naming the pinned protocol version before it will run anything. That is §8.4, and there is no arrangement of arguments that turns it off.

The page loads assets/avm.wasm — the AVM and its in-memory world state, about 1.6 MB — and the Token contract artifact, both lazily. It does not load the barretenberg proving wasm: poseidon2 comes out of avm.wasm, which is itself a barretenberg build, so the page does not download a second one (DD-11).

This button exists so the check that says “the proving wasm is never fetched” can be shown to be capable of seeing one.
